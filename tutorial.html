How to Use AgentFarm 🚀

Quick Start Guide

  1. Open a Github issue and write your request – you don't need to be thorough
  2. The agent will open a PR. Reply to the agent in the PR
  3. When you're happy with the agent's work, merge

What AgentFarm Can Do ✨

With AgentFarm, you can spawn multiple agents on your codebase. The agents can:

  • 💻 Write code
  • 🔍 Search your codebase
  • 🖥️ Use the terminal

In other words, you can assign them any task you would give a mid-level engineer. They will act autonomously, and continue working in the background even if you close your repo.

Examples

The agents can:

  • Add new features
  • Fix bugs
  • Start projects from scratch
  • Include and run tests for each new piece of logic

You'll be surprised to see how much work can be done – and you'll be able to focus your attention on more mission-critical aspects of your product and company.
